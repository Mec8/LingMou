# 🦞 灵眸 Dashboard (LingMou)

**全新重构 · 简洁高效 · 实时监控**

---

## 🚀 快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 启动服务
cd dashboard
python server.py

# 3. 访问 Dashboard
# 浏览器打开：http://localhost:2026
```

---

## ✨ 核心功能

- 📊 **实时统计** - 任务数、Agent、Token、费用

- 💰 **Token 统计** - 实时用量和费用
